AWS Certified Generative AI Developer - Professional (AIP-C01) Study Guide
==========================================================================

EXAM OVERVIEW
-------------
- Exam code: AIP-C01
- Level: Professional
- Cost: $300 USD
- Duration: 170 minutes
- Questions: 65 scored + 10 unscored = 75 total
- Passing score: 750/1000 (compensatory scoring - no per-domain minimum)
- Valid for: 3 years

EXAM DOMAINS AND WEIGHTINGS
----------------------------
Domain 1: Foundation Model Integration, Data Management, and Compliance - 31%
Domain 2: Implementation and Integration - 26%
Domain 3: AI Safety, Security, and Governance - 20%
Domain 4: Operational Efficiency and Optimization - 12%
Domain 5: Testing, Validation, and Troubleshooting - 11%

- Amazon Bedrock Knowledge Bases

- Amazon Kendra for enterprise search
- Data management and compliance for AI workloads
- Chunking strategies for document ingestion
- Embedding models and vector dimensions

Key AWS Services for Domain 1:
- Amazon Bedrock (primary service - know deeply)
- Amazon OpenSearch Serverless
- Amazon Kendra
- Amazon S3 (document storage)
- AWS Glue (data preparation)

PROMPT ENGINEERING TECHNIQUES
-------------------------------
1. Zero-shot: Direct instruction without examples
2. Few-shot: Provide examples before the task
3. Chain-of-thought: Ask model to reason step by step
4. System prompts: Set behavior and constraints
5. Role prompting: Assign a persona to the model
6. Output formatting: JSON, XML, structured data
7. Constitutional AI: Self-critique and revision
8. ReAct: Reason + Act pattern for agents

RAG ARCHITECTURE PATTERNS
--------------------------
1. Naive RAG: Retrieve → Augment → Generate
2. Advanced RAG:
   - Query rewriting
   - Hybrid search (semantic + keyword)
   - Reranking retrieved chunks
   - Metadata filtering
3. Modular RAG:
   - Multiple retrieval sources
   - Dynamic retrieval strategies
4. Key parameters:
   - Chunk size (typically 256-512 tokens)
   - Chunk overlap (10-20%)
   - Top-K retrieval (typically 3-10)
   - Similarity threshold

BEDROCK AGENTS ARCHITECTURE
-----------------------------
Components:
1. Foundation Model: The reasoning engine
2. Action Groups: Lambda functions the agent can call
3. Knowledge Bases: RAG data sources
4. Session Management: Multi-turn conversation
5. Orchestration: Planning and execution loop

Agent execution loop:
1. Receive user input
2. Reason about what actions to take (ReAct)
3. Call action group (Lambda)
4. Process tool results
5. Continue reasoning or return final answer

VECTOR DATABASE CONCEPTS
-------------------------
- Embeddings: Dense vector representations of text
- Cosine similarity: Measure of vector similarity
- Approximate Nearest Neighbor (ANN): Fast similarity search
- HNSW: Hierarchical Navigable Small World graph algorithm
- Dimensions: all-MiniLM-L6-v2 = 384, text-embedding-3-small = 1536
- Metadata filtering: Filter by document attributes before vector search

EXAM TIPS
----------
1. Domain 1 is 31% - prioritize Bedrock and RAG
2. You will read code snippets - know Python Bedrock API calls
3. Scenario-based questions - focus on WHY not just WHAT
4. Know the difference between Kendra and OpenSearch Serverless
5. Guardrails is heavily tested in Domain 3
6. Lambda + Bedrock Agents is a common pattern
7. Compensatory scoring - no need to pass each domain separately
8. 170 minutes for 75 questions = ~2.3 minutes per question
